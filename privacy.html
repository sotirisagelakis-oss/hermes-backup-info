Hermes Backup — Privacy Policy

Hermes Backup is a personal Google Drive integration operated by the owner of sotirisagelakis-oss. It is intended for the operator's own account and files, not for public registration.

Information accessed and purpose

The integration uses Google OAuth authorization and the Google Drive API. Within the permissions approved by the owner, it may access file names, identifiers, sizes, hashes, metadata and file contents to locate existing backups, upload selected files, verify transfers and restore data when requested. Full Drive permission, when approved, permits access beyond files created by this application; the intended use remains the owner's backup and file-transfer operations.

Storage and protection

OAuth credentials are stored on the operator's own computer with restricted access. Backup copies are stored on the operator's devices and in their Google Drive. Configured full-backup archives are encrypted before upload. Files separately selected for transfer, including a recovery key if explicitly requested, are not necessarily encrypted by the integration. Keeping a key in the same cloud account as encrypted backups reduces their protection against compromise of that account.

Use and disclosure

Google user data is used only to provide these personal backup and file-transfer functions. It is not sold, used for advertising or used to train generalized AI or machine-learning models by this Drive integration. This informational GitHub Pages website does not receive or display Drive file contents, OAuth credentials or backup files.

Hermes Backup's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention, deletion and control

Files remain in the owner's chosen destinations until removed under the owner's instructions or configured retention policy. The owner can revoke the application's access in their Google account connections, remove local OAuth credentials and delete cloud or local files. Deleting a visible file does not guarantee immediate erasure from a provider's retained backups.

Website hosting

These static pages have no analytics scripts, upload forms, advertising or application-set cookies. GitHub Pages may process visitor network and request information under the GitHub Privacy Statement. Google's services are subject to Google's own policies.

Contact and changes

The operator can be contacted through their GitHub profile. This policy may be updated if the integration's operation changes.
