Hermes Backup

A personal backup integration operated by the owner of the GitHub account sotirisagelakis-oss.

Purpose

Hermes Backup uses rclone and the Google Drive API to store and verify the owner's backups and transfer files explicitly selected by the owner. It is a private-use integration, not a public file-storage service.

Google account access

Google authorization is granted directly by the account owner. Depending on the authorized scope, the integration can list and read Drive files, upload files, and manage its backup files. Access to existing backups may require full Drive access rather than access limited to files created by the new OAuth application.

This website

This site contains only application information and a privacy policy. It does not provide login, accept uploads, or publish backups, credentials, recovery keys, or Drive file contents.
